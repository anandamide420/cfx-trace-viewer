Calculation and interpretation

Imported LIDAR and SYBR standard curves

Six tenfold gBlock dilutions per assay, spanning five log intervals. Points and fitted coefficients are imported from the prior publication dataset, rather than generated from the EN9581 plate.

Original calibration amplification traces

These are the original exported amplification RFUs. Imported standard-curve Cqs and fitted coefficients remain fixed; EN9581’s baseline and threshold controls do not recompute them.

Primer-aligned amplicon lengths

Exact matches to the bundled reference gBlocks, counted from the first forward-primer base through the last reverse-primer base. Original oligo names and instrument labels are retained for traceability.

Column 1 uses Pfizer_Spike_40bp (46 bp aligned) and Ori_48bp (48 bp aligned). The Ori choice follows the operator’s initial identification; alignment verifies the sequence span, not which oligo was pipetted. The alternate Ori_45bp oligo would produce 45 bp.

Selected-run preparation

The 400 bp gBlock mass convention is retained. Bundled reference sequences are 401 nt; using 401 bp would reduce inferred copies by approximately 0.25%. Biological row assignments and aligned lengths are used in calculations; original instrument labels remain in the source data.

gBlock stock concentration measurements

Calculator defaults use the equal-weight arithmetic mean of the four supplied values for each target: Spike (1 + 0.535 + 1.36 + 3.0) / 4 = 1.47375 ng/µl; Ori (1 + 0.340 + 0.700 + 2.0) / 4 = 1.01 ng/µl. These editable stock defaults apply to both lots on this plate. Dilution factors are specific to each run. The IDT value was supplied as the manufacturer-reported concentration; the other values were read from the operator’s measurement screenshots. Electrophoresis uses the main-peak concentration and excludes markers and minor higher-size peaks.

This is an operator-selected arithmetic average across methods, not four replicate measurements or an uncertainty-weighted estimate. No additional premeasurement dilution correction is applied. The average changes the independently supplied stock input; vaccine Cqs are not used to adjust it. Historical standard-curve points and efficiencies retain their original reported calibration basis.

Run inclusion

This standalone edition contains the 19 October EN9581 versus FL8095 SYBR benchmark the subsequent no-SYBR v2 plate, the S+O+SYBR duplicate plate, and the 20 October SYBR and TaqMan dilution plates, plus three historical calibration series. Earlier versions remain separate files.
